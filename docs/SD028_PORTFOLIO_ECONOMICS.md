# SD-028 SPY/QQQ joint portfolio economics

This is a deterministic, proposal-only audit over the existing ignored
five-year SIP bundles. It aligns the 1,254 common sessions, compounds a daily
50/50 equal-weight price-only ledger, and compares it with the weighted
price-only buy-and-hold benchmark.

| Measure | Result |
|---|---:|
| Common sessions | 1,254 |
| SPY / QQQ weights | 50% / 50% |
| Cash weight / gross exposure | 0% / 100% |
| Maximum concentration | 50% |
| Return correlation | 0.947673 |
| Joint portfolio ending equity | 1.804260 |
| Weighted price-only benchmark | 1.798820 |
| Joint portfolio price-only return | 80.43% |
| Maximum drawdown | 30.33% |

The high correlation means the pair is overlapping broad-market exposure; no
diversification or trading approval is inferred. Transaction costs and
turnover are explicitly `NOT_APPLIED` because no rebalance schedule or order
ledger is present. Regime sensitivity remains `NOT_ASSESSED`. Dividends and
ETF distributions remain outside the price-only benchmark.

The reproducible output is `data/sd028-portfolio-economics.json` (ignored local
artifact), generated by `sd028_portfolio_economics.py`. Broker execution is
disabled.
